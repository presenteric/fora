# Via — Trust Bridge prototype

Single-file static prototype for a final-round interview at [Fora](https://www.foratravel.com/), exploring **Via** (Fora's AI agent for travel advisors) and a "trust bridge" between external LLMs and Fora's bookable inventory.

Live at **[fora.presenteric.com](https://fora.presenteric.com)**.

## What's in here

One file: `index.html`. Inline CSS and JS. No build step, no dependencies.

The prototype walks three screens of a Phase 1 demo (advisor inbox → Via's outline → itinerary builder), then sketches two preview screens for Phases 2 and 3 of the roadmap.

## Run locally

```bash
open index.html
```

Or serve it:

```bash
python3 -m http.server 8000
```
